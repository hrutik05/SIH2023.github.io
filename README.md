# 🌐SIH 2023 – E Waste Facility Locator (Runner-Up)

This repository hosts the static website created for the **Smart India Hackathon 2023**, showcasing project details, FAQs, team information, and more via an engaging, responsive design.

---

##  🧾Project Overview

The site is structured as a **GitHub Pages** personal (or project) website, deployed from the repository `SIH2023.github.io`. It provides information related to the hackathon, such as key project documentation, FAQs, contact information, and a styled blog section, all within a visually appealing and easy-to-navigate interface.

---

##  ✨Features

- **Responsive design** using Bootstrap and custom CSS
- Interactive elements including carousels and popups with Owl Carousel and Magnific Popup
- Structured navigation with multi-page support (Home, Blog, FAQ, Contact)
- Embedded static documentation (PDF): *Metal Rate in E Waste*
- Smooth user experience with jQuery-based enhancements (e.g., counters, mobile navigation)

---

## 🛠️Technologies Used

- **HTML5** – Core website structure (`.html` pages)
- **CSS3** – Styling and layout
  - **Bootstrap** – Responsive grid and components (`bootstrap.min.css`)
  - **Owl Carousel**, **Magnific Popup**, **SlickNav** – UI components and navigation
- **JavaScript** – Interactivity and animations
  - **jQuery** – DOM manipulation and plugins
  - **Custom scripts** – `main.js`, `jquery.counterup.min.js`, `slicknav.min.js`
- **Static Assets** – Images (e.g., blog1.jpg, client images), PDF files, favicon, etc.
